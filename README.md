# FPGA 기반 디지털 시계 (Verilog)

## 프로젝트 개요
- **기간**: 논리회로실험 과목 기말 프로젝트
- **목적**: Verilog HDL로 Clock / Setup / Alarm / Timer 4개 모드를 지원하는 디지털 시계를 설계하고, IR 리모컨(NEC 프로토콜) 입력을 처리해 FPGA 보드에서 실제 동작을 검증
- **역할**: FSM 및 전체 모듈 설계, 테스트벤치 작성, FPGA 구현 및 디버깅

## 사용 기술
- **언어/툴**: Verilog HDL, Questa (시뮬레이션), Quartus (합성 및 구현)
- **보드**: Cyclone IV FPGA

## 설계 내용
- 시간 계수, 모드 제어, 클록 분주(clock divider), 6자리 7-Segment 표시, LCD 출력, 부저, IR 리모컨(NEC 프로토콜) 수신 및 디코딩을 각각 모듈화
- 각 모듈을 최상위 모듈에서 통합해 Clock/Setup/Alarm/Timer 4개 모드로 동작하는 전체 시스템 구성
- Questa로 테스트벤치를 작성해 waveform 기반 기능 검증 진행 후, Quartus에서 핀 할당 및 FPGA 다운로드로 실제 보드 동작 확인

## 문제 해결 과정
버튼(리모컨)을 눌렀을 때 해당 입력이 즉시 반영되지 않고, **다음 버튼을 눌렀을 때 이전 입력에 해당하는 동작이 실행되는 문제**가 발생했습니다.

- **문제 파악**: 특정 버튼 하나의 로직 오류라면 다른 버튼에서는 문제가 없어야 하는데, 여러 버튼에서 동일한 현상(한 입력씩 밀려서 반영)이 반복되는 것을 확인했습니다.
- **원인 분석**: 이를 통해 개별 버튼의 로직 오류가 아니라, NEC 프로토콜로 수신한 데이터를 내부 FSM에 전달하는 **타이밍 문제**로 원인 범위를 좁혔습니다. 신호가 들어오는 시점과 FSM이 이를 인식해 상태를 갱신하는 시점 사이에 한 클록 사이클의 지연이 있어, 입력이 한 박자 늦게 반영되고 있었습니다.
- **해결**: FSM에 중간 상태(intermediate state)를 추가해 수신 데이터의 전달 시점을 조정, 버튼 입력이 지연 없이 즉시 반영되도록 구조를 개선했습니다.

## 결과
- Clock, Setup, Alarm, Timer 4개 모드와 IR 리모컨 제어가 지연 없이 정상 동작하는 것을 실제 FPGA 보드에서 확인
- 기능 구현뿐 아니라 상태 전이와 데이터 갱신 시점까지 고려하는 타이밍 검증 역량을 키움
- (실제 보드 동작 사진/영상, 블록 다이어그램, FSM 상태도 등을 추가하면 좋습니다)

## 배운 점
- 여러 지점에서 동일한 패턴의 오류가 반복될 때는 개별 로직보다 데이터 전달 경로의 타이밍을 먼저 의심해야 한다는 것을 체감
- HDL 설계 시 시뮬레이션만으로 드러나지 않는 타이밍 이슈를, FSM 상태 설계 단계에서부터 고려하는 것이 중요함을 배움
